# From references to a useful research board

This ten-minute walkthrough uses a small research question: **what makes a
public space feel welcoming?** Substitute an art study, a product idea, family
memories, or the subject you are investigating. The workflow is the same.

## 1. Collect a small set

Create a board named **References**. Drop in three photographs, a PDF report,
and a text or Word document. Start with material you already have permission
to use. Put a short note at the top containing the question you want to answer.

PDFs show their first page. Word documents become editable plain text, so
headings and formatting are not preserved. The original document stays intact.

## 2. Put your observations beside their sources

Beside each photograph, add a note describing one specific thing you noticed:
“Seats face each other,” for example, or “The entrance is hard to find.”
Connect each note to its photograph and give the connection the **source**
meaning. Label a connection when its meaning needs more explanation.

For an observation about one part of an image, use a research capture in the
item panel and mark the region. That keeps the note attached to the detail
that prompted it.

## 3. Make disagreement visible

Move similar observations near each other. Add tags such as `seating`,
`access`, and `lighting`. When two references point in different directions,
connect them with **contradiction** and write why. Leave an unanswered point
as a note tagged `question`; you do not need to force a conclusion.

The board is useful when it shows what you think and which material supports
it, not just a collection of attractive references.

## 4. Find it again

Create a second board named **Conclusions** and write three tentative findings.
Open search and look for `tag:seating` to retrieve related material across the
project. Use `board:References` to narrow the results. Clicking a result takes
you back to the board that contains it.

If you have an audio interview or voice memo, right-click the audio item and
choose **Transcribe**. Choose or download a model in Settings first. The
transcript becomes editable, searchable text beside its recording. Recognition
is local, and downloading the model is an explicit separate action.

## 5. Save something you can return to

Save a `.citadel` project for continued work. Local media is referenced by
path, so moving the original files can break those references. Use a
`.citadelz` archive when you need a portable copy with bundled assets.

For written notes outside Citadel, export Markdown and open it in your editor
or Obsidian vault. The text, source links, and relationships leave as an
ordinary file; the spatial arrangement stays in Citadel.

## Try it without installing

The [browser demo](https://kannibalkwi.itch.io/citadel) opens the built-in
example project. You can arrange and edit its contents to explore the canvas.
Importing your own files, saving, transcription, and desktop window controls
require the desktop app. Demo changes reset when the page reloads.

If you try this workflow, the most useful feedback is the point where you
could not do what you expected, along with your platform and app version.
The [bug report thread](https://itch.io/t/6813785/bug-reports) and
[feature request thread](https://itch.io/t/6813788/feature-requests) are open.
