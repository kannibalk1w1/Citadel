# UI Scale Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a UI Scale control (75% / 100% / 125% / 150%) to Fun Settings that scales the entire app window using Electron's `webContents.setZoomFactor()`, persisted across restarts.

**Architecture:** A new `zoom:set` IPC channel in the main process applies the zoom factor to the sender's webContents and persists it alongside existing settings. The renderer-side `uiStore` holds the display value and calls that channel on change. App.tsx loads the persisted value on startup. The UI is a `−` / `+` row in the existing Fun Settings section of KeybindSettings.tsx.

**Tech Stack:** Electron IPC, Zustand, React, Vitest

### Task 1: Add zoom:set IPC handler

**Files:**
- Modify: `src/main/ipc.ts`

- [ ] **Step 1: Read the settings handlers for context**

Read `src/main/ipc.ts` around lines 137–149 to see the `settings:get` and `settings:set` handlers. Note that they use `readSettings()` and `writeSettings(settings)`. The new `zoom:set` handler follows the same pattern.

- [ ] **Step 2: Add the zoom:set handler after the settings:set handler**

In `src/main/ipc.ts`, after the closing `})` of the `settings:set` handler (around line 149), add:

```ts
  // ── zoom:set ───────────────────────────────────────────────────────────────
  ipcMain.handle('zoom:set', async (e, { factor }: { factor: number }) => {
    const clamped = Math.min(1.5, Math.max(0.75, factor))
    e.sender.setZoomFactor(clamped)
    const settings = readSettings()
    settings['ui.zoomFactor'] = clamped
    writeSettings(settings)
    return { ok: true }
  })
```

- [ ] **Step 1: Write the failing tests**

// @vitest-environment jsdom
import { describe, it, expect, vi, beforeEach } from 'vitest'
import { useUIStore } from './uiStore'

const mockInvoke = vi.fn().mockResolvedValue({ ok: true })

beforeEach(() => {
  Object.assign(window, {
    ipc: { invoke: mockInvoke },
  })
  mockInvoke.mockClear()
  useUIStore.setState({ uiScale: 1.0 })
})

describe('uiStore — uiScale', () => {
  it('defaults to 1.0', () => {
    expect(useUIStore.getState().uiScale).toBe(1.0)
  })

  it('setUiScale updates uiScale', () => {
    useUIStore.getState().setUiScale(1.25)
    expect(useUIStore.getState().uiScale).toBe(1.25)
  })

  it('setUiScale clamps values below 0.75 to 0.75', () => {
    useUIStore.getState().setUiScale(0.5)
    expect(useUIStore.getState().uiScale).toBe(0.75)
  })

  it('setUiScale clamps values above 1.5 to 1.5', () => {
    useUIStore.getState().setUiScale(2.0)
    expect(useUIStore.getState().uiScale).toBe(1.5)
  })

  it('setUiScale calls zoom:set IPC with clamped factor', () => {
    useUIStore.getState().setUiScale(1.5)
    expect(mockInvoke).toHaveBeenCalledWith('zoom:set', { factor: 1.5 })
  })
})
