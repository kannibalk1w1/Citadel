# PDF Drop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add support for dropping PDF files onto the canvas, rendering page 1 into a cached PNG image item.

**Architecture:** Use PDF.js in the renderer to render page 1 into a browser canvas, then send the PNG data URL through IPC for main-process cache writing. Create a normal `image` CanvasItem using the cached PNG path and source PDF metadata.

**Tech Stack:** React, TypeScript, Electron IPC, PDF.js, Canvas 2D.

---

## Task 1: Dependency and IPC

**Files:**
- Modify `package.json`
- Modify `package-lock.json`
- Modify `src/main/ipc.ts`

- [ ] Install `pdfjs-dist`.
- [ ] Add IPC channel `pdf:cachePageImage`.
- [ ] Channel input: `{ pdfPath: string; page: number; imageData: string }`.
- [ ] Channel writes PNG bytes to `join(app.getPath('userData'), 'pdf-cache')`.
- [ ] Channel returns `{ path: string }`.
- [ ] Run `npm.cmd run build`.
